# Agents Overview

This document provides an overview of the Windows System Agent (WinAgent) architecture, its tools, skills, plugins, and sub‑agents.

## High‑level Architecture
- **Core engine** (`src/index.js`) orchestrates tasks, loads skills, and manages memory.
- **Tools** – 63 built‑in actions ranging from file operations, app control, screen interaction, browser automation, system services, and more.
- **Skills** – Markdown playbooks placed in `skills/` that the agent can load at runtime. Examples: `github`, `computer-use`, `dashboard`.
- **MCP Plugins** – External servers expose additional capabilities via `mcp_<server>_<tool>` functions.
- **Sub‑agents** – Specialized agents (e.g., Flutter agents) that can be spawned for domain‑specific tasks.
- **Configuration** – `.env` defines model connection; `overlay-agent.json` configures overlay behavior.

## Skills (Playbooks)
Skills are markdown files in `skills/`. The agent loads them automatically based on triggers. Key skills include:
- `github` – pushes changes, handles auth.
- `computer-use` – screenshot → ground → act → verify loop.
- `dashboard` – runs the local web UI.
- `self-learn` – research and update skills.

## MCP Plugins
Declared in `plugins/`. Each provides tools prefixed with `mcp_<server>_`. Example:
- `gemini-api-docs` – `gemini_search_docs`, `gemini_get_doc`.

## Sub‑agents
Located under `agents/` in plugins (e.g., Flutter agents). They can be invoked via `task_delegate`.

## Configuration
- **Model** – set in `.env` (`MODEL_API_URL`, `MODEL_API_KEY`, `MODEL_NAME`).
- **Overlay** – settings in `overlay-agent.json` control UI overlay behavior.
- **Safety** – `REQUIRE_APPROVAL`, `ALLOWED_ROOTS`, `BLOCKED_PATHS`.

## Usage Example
```powershell
node src\\index.js "list files in Documents"
node src\\index.js --skill github "push my latest changes"
```

## Updating the Project
When changes are made, run:
```powershell
git add AGENTS_OVERVIEW.md
git commit -m "Add agents overview documentation"
git push
```
The `github` skill can also handle authentication and push.
